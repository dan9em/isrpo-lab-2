# Geometric lib

## Описание решения
Репозиторий имеет два файла: *circle.py* и *square.py*. С помощью этих программ можно соответственно вычислять следующие значения:
1. Площадь круга и периметр круга
2. Площадь квадрата и периметр квадрата


## Описание функций

### Для файла *circle.py*:

***area(r)*** принимает на вход радиус круга r и выдает его площадь по формуле S = πR<sup>2</sup>\
Примеры использования:

- `area(1)` выдаст результат ~3.14 (число π)
- `area(3)` выдаст результат ~9.42

***perimeter(r)*** принимает на вход радиус круга r и выдает его периметр по формуле P = 2πR.\
Примеры использования:

- `perimeter(1)` выдаст результат ~6.28
- `perimeter(0.5)` выдаст результат ~3.14

### Для файла *square.py*:

***area(a)*** принимает на вход длину стороны a квадрата и выдает его площадь по формуле S = a<sup>2</sup>.\
Примеры использования:

- `area(2)` выдаст результат 4
- `area(3)` выдаст результат 9

***perimeter(a)*** принимает на вход длину стороны a квадрата и выдает его периметр по формуле P = 4a.\
Примеры использования:

- `perimeter(1)` выдаст результат 4
- `perimeter(0.5)` выдаст результат 2
